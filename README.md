# bank_reviews_clustering
Анализ отзывов о банках: EDA + TF-IDF + K-Means

## Описание
Проанализировано 12 392 отзыва о банках. Проведён EDA, затем кластеризация текста с помощью TF-IDF и K-Means. Выделено 5 кластеров: карты и кэшбэк, благодарности, жалобы на обслуживание, позитив о Тинькофф, негатив про карты.

## Стек
- Python (Pandas, NumPy)
- Scikit-learn (TF-IDF, K-Means, PCA)
- Matplotlib, Seaborn

## Результаты
- Средняя оценка: 2.85.
- Самый негативный кластер — «Негатив про карты» (средняя оценка 1.65).
- Самый позитивный — «Благодарности» (4.92).
- Негативные отзывы длиннее позитивных.
